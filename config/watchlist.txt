#  TICKERS THE BRIEFING COVERS
# ============================================================
#
#  To ADD a ticker:     put the ASX code on its own line,
#                       followed by its commodity code.
#  To REMOVE a ticker:  delete its line.
#  To PAUSE a ticker:   put a # at the start of its line.
#
#  One code per line. Case does not matter. The word after the
#  code is the commodity, from config/commodities.txt (Au, Cu,
#  U ...). Leave it off and the name goes to the default, which
#  is the first commodity listed there. A comment after that is
#  fine and is useful for noting why the name is here:
#
#      PGO    Au    # Pacgold, White Dam
#      BOE    U     # Boss Energy, Honeymoon
#
#  If a company changes its ASX code, add the new code and
#  comment out the old one with a note, so the history stays
#  readable. Example already below: KAI became PGL in
#  April 2026.
#
# ============================================================
